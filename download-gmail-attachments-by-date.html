How to download Gmail attachments by date range

By the AttachmentDownloader project · Updated October 30, 2026

Use has:attachment after:2026/01/01 before:2027/01/01 to find Gmail messages with attachments in a year-long window. To download files from the matching messages together, apply a date range in AttachmentDownloader, review the results and save your selection as a ZIP.

Search a month, year or rolling period

Gmail's date search applies to the email's date, not the date a document was created or last edited. Combine it with a sender or file type when you need a smaller result set.

Download the matching attachments

  1. Open AttachmentDownloader, sign in with Google, then connect Gmail with read-only access.
  2. Set the After and Before date filters, or paste a date query into the Gmail search field.
  3. Optionally add a sender, label or file-type filter. Use the PDF filter when you want only PDF attachments.
  4. Choose Find attachments and review the dates and filenames. Select individual files or choose Select all.
  5. Choose Download ZIP for multiple selections, or Download file for one file.

Include the last day of your date range

The Before boundary excludes the specified day. To include October 31, use November 1 as the Before date. The app sends its date filters using Gmail's after: and before: search operators.

If you are working with exact cutoffs, check messages near midnight against Gmail's results. Google's API interprets date strings using its documented timezone rules; an email near a boundary can fall on a different calendar day from the one displayed on your device. See Google's API date and timezone guidance.

Split a large mailbox into smaller batches

One search stops at 25,000 messages or 10,000 attachments. If the app reports that it reached the limit, narrow the range and search again. Monthly or weekly batches make it easier to check the results and retry an interrupted download.

Keep track of each batch's After and Before values and check the boundary messages, especially for records where completeness matters. Don't assume that a search which hit its limit contains every file in the period.

What the date filter does not do

  • It does not read invoice dates printed inside PDFs or dates in filenames.
  • It does not fetch files that were only shared as Google Drive links.
  • It does not schedule recurring backups. The browser page must stay open while a search or download runs.
  • It does not delete or modify Gmail messages.
