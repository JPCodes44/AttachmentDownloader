How to download all attachments from one sender in Gmail

By the AttachmentDownloader project · Updated October 30, 2026

Search Gmail for from:sender@example.com has:attachment to list every email with attachments from that sender. Gmail then makes you open each email to save its files. To get them all at once, run the same search in AttachmentDownloader and download every file as one ZIP.

Find a sender's attachments in Gmail

Type one of these into the Gmail search bar:

  • from:anna@example.com has:attachment for one person.
  • from:@example.com has:attachment for everyone at a company.
  • from:anna@example.com filename:pdf for only their PDFs.
  • from:anna@example.com has:attachment after:2026/01/01 for this year only.

This shows the emails, but Gmail has no way to download attachments from several emails together. You'd open each one and click Download all.

Download them all as one ZIP

  1. Open AttachmentDownloader, sign in with Google, then connect Gmail in the browser. Google grants read-only access.
  2. Type the sender's name, email address or domain (such as example.com) in the From box.
  3. Optionally pick a date range, a minimum size, or file types like PDFs or images.
  4. Click Find attachments, then Select all and Download ZIP.

Duplicate filenames are renamed automatically, so two files called invoice.pdf don't overwrite each other in the ZIP.

Every attachment from one sender, in one ZIP. Free, read-only, nothing to install.

Common uses

  • Invoices and receipts from a supplier or service, for your accountant or taxes.
  • Photos a family member sent over the years.
  • Contracts and documents from a client or lawyer.
  • Statements from your bank or utility company.

Narrow a supplier's files by type and period

For invoices, combine the sender with the PDF filter and a date window. Read how to download only PDF attachments and how Gmail date boundaries work. A subject search such as subject:invoice narrows matching emails; it does not classify the contents of each document.

One search stops at 25,000 messages or 10,000 attachments. If it reaches that limit, search smaller date ranges. A single selected file downloads directly; multiple selections download as a ZIP.

Questions

Can I include several senders?

Yes. Edit the Gmail search box in AttachmentDownloader to something like from:(anna@example.com OR ben@example.com).

Does it include images pasted inside the email?

Only if you turn on Include inline images. By default you get real attachments, not logos and signatures.
