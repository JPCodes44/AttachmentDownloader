About AttachmentDownloader

AttachmentDownloader is a free web app for finding files across Gmail messages and downloading the files you choose together. You can filter by sender, date, label and file type instead of opening each message separately.

What the app does

Connect Gmail, run a search and review the matching attachments. Download a single file or package multiple files as one ZIP. The app leaves your emails and original attachments in Gmail.

How access and privacy work

Google account sign-in and Gmail permission are separate steps. Signing in uses your basic profile for your app account. Connecting Gmail grants a short-lived, read-only Gmail token directly to your browser.

Gmail searches, message details, attachment downloads and ZIP creation run in your browser. The Gmail access token and file contents are not sent to our website server or account backend. Read-only access cannot send, change or delete email. The website uses no advertising or analytics trackers.

Disconnect Gmail in the app to revoke the browser's token, or remove access from your Google Account's third-party connections. The privacy policy explains account storage and deletion in full.

Limits to know before downloading

  • One search stops at 25,000 emails or 10,000 attachments. Split larger searches by sender or date.
  • Your browser, device resources, connection and Google's API limits affect large downloads. Keep the page open until the download finishes.
  • Drive links are not email attachments. Open shared Drive files separately with the necessary permission.
  • The app does not bypass Gmail security restrictions, PDF passwords or workplace access policies.
  • This is an on-demand download tool; it does not run scheduled backups or merge PDF documents.

Source code and support

The project is maintained at JPCodes44/AttachmentDownloader on GitHub. You can review the source or report an issue. When reporting a problem, describe the steps and error message; do not post email contents, access tokens or private attachments.
