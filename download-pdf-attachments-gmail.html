How to download all PDF attachments from Gmail

By the AttachmentDownloader project · Updated October 30, 2026

Search Gmail with has:attachment filename:pdf to find messages containing PDFs. Gmail shows matching emails; it does not offer a bulk download of PDFs across those messages. AttachmentDownloader can list the matching PDF files and download your selection together.

1. Find the right PDFs

Start with one of these queries in Gmail or in the app's Gmail search box. Replace the example sender and dates with your own.

A subject search finds emails mentioning that word; it cannot tell whether a file is actually an invoice. Check the filenames and subjects before selecting files. For date boundaries, see the date-range guide.

2. Download PDF attachments together

  1. Open AttachmentDownloader and sign in with Google.
  2. Choose Connect Gmail and review Google's read-only permission request.
  3. Select the PDF file type. Add a sender, date range or Gmail search if needed.
  4. Choose Find attachments. Review the sender, subject, filename and size in the results.
  5. Select the PDFs you want, or choose Select all. Choose Download ZIP for multiple files; a single selection uses Download file.

Use the PDF file-type filter even if your query contains filename:pdf. Gmail searches messages: a matching email may contain a PDF and other files. The app's PDF filter also checks individual attachment filenames, so the download selection stays limited to PDFs.

What happens to the files?

The app copies the original attachments; it does not merge PDFs, convert email bodies into PDFs, or delete email. Multiple files are packaged in one ZIP, which you extract on your device. Duplicate filenames receive distinct names to avoid overwriting each other inside the ZIP.

Gmail searches and attachment downloads run directly between your browser and Google. File contents and the Gmail access token are not sent to our backend. Account sign-in stores your basic Google profile separately. Read the privacy policy for details.

Limits and missing PDFs

  • Drive links are separate: a link to a PDF in Google Drive is not an attached PDF. Open it in Drive using the owner's permissions.
  • Large exports: one search stops at 25,000 messages or 10,000 attachments. Use smaller sender/date batches and keep the page open while downloading.
  • Protected files: downloading does not remove PDF passwords, Gmail security restrictions or workplace policies.
  • Filename matching: the PDF filter uses the filename extension; inspect any unexpectedly named files.

Can I do this without connecting another app?

Yes. In Gmail, open each matching email and download its PDFs manually. For a complete mailbox archive, consider Google Takeout; it exports mail rather than a folder of selected PDFs. See the comparison of four download methods.

Search syntax reference

The examples use Google's documented filename:, from:, subject:, after: and before: operators. Read Google's Gmail search documentation.
